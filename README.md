# 量潮叙事工程实验报告

叙事工程框架的领域模型与方法实验验证。领域模型涵盖母题、风格等叙事要素的表征与计算；方法涵盖评审、分析、生成等编辑流程。

## 领域模型

叙事要素的可计算表征：

| 模型 | 实验 | 核心问题 |
|------|------|---------|
| **叙事结构** | p01 | 用什么框架标注段落叙事角色？起承转合 vs 三幕 vs 情感曲线 |
| **风格与审美** | p03, p09 | 文字风格能否聚类归因？作者的审美偏好能否被编码和复刻？ |
| **母题** | p05–p07 | 叙事中反复出现的主题元素——能否提取、跨作品识别、约束生成？ |
| **母题+风格合成** | p08, p10 | 母题缝隙分析与多向改进建议；组合改法是否优于单层？ |
| **场景情节** | p14, p15 | 场景内行为因果链诊断与建议；从 YAML 自动生成写作提纲 |
| **读者模型** | p16 | 能否通过结构化 prompt 模拟差异化读者视角做群体仿真？ |

## 实验管线

```
领域模型                               方法
──────────────────────────────────────────────────
叙事结构                   母题链                         风格与审美
────────────────────────────────────────────────────────────────────
p01 结构框架选型

p03 风格聚类 ─────────────────────────→ p09 审美复刻

           p05 提取 ──→ p06 跨作品识别 ──→ p07 约束生成

           p08 缝隙分析 ──→ p10 母题+风格合成

p18 角色驱动的情节推理 / 一致性检查 / 写作备忘

p16 模拟读者 (reader)
```
