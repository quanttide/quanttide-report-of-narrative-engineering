# 量潮叙事工程实验报告

叙事工程框架的领域模型与方法实验验证。领域模型涵盖母题、风格等叙事要素的表征与计算；方法涵盖评审、反思、重写等将初稿迭代至成稿的编辑流程。

## 领域模型

叙事要素的可计算表征：

| 模型 | 实验 | 核心问题 |
|------|------|---------|
| **叙事结构** | p01 | 用什么框架标注段落叙事角色？起承转合 vs 三幕 vs 情感曲线 |
| **母题** | p05–p07 | 叙事中反复出现的主题元素——能否提取、跨作品识别、约束生成？ |
| **风格与审美** | p03, p09 | 文字风格能否聚类归因？作者的审美偏好能否被编码和复刻？ |

## 方法

3R 工作流（Review→Reflect→Rewrite）的每个环节：

| 环节 | 实验 | 能力 |
|------|------|------|
| **Review** 评审 | p04, p09 | LLM 理解评审意图；内化作者审美标准进行评审 |
| **Reflect** 反思 | p02, p08 | 3R 管线验证；检测母题缝隙并推荐改进方向 |
| **Rewrite** 重写 | p07 | 以母题为约束引导生成，保持叙事一致 |
