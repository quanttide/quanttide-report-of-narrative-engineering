# 量潮叙事工程实验报告

叙事工程框架的领域模型与方法实验验证。领域模型涵盖母题、风格等叙事要素的表征与计算；方法涵盖评审、分析、生成等编辑流程。

## 领域模型

叙事要素的可计算表征：

| 模型 | 核心问题 |
|------|---------|
| **叙事结构** | 用什么框架标注段落叙事角色？起承转合 vs 三幕 vs 情感曲线 |
| **风格与审美** | 文字风格能否聚类归因？作者的审美偏好能否被编码和复刻？ |
| **母题** | 叙事中反复出现的主题元素——能否提取、跨作品识别、约束生成？ |
| **母题+风格合成** | 母题缝隙分析与多向改进建议；组合改法是否优于单层？ |
| **场景情节** | 场景内行为因果链诊断与建议；从 YAML 自动生成写作提纲 |
| **读者模型** | 能否通过结构化 prompt 模拟差异化读者视角做群体仿真？ |

## 实验管线

```

           提取 ──→ 跨作品识别 ──→ 约束生成

           缝隙分析 ──→ 母题+风格合成

角色驱动的情节推理 / 一致性检查 / 写作备忘

模拟读者 (reader)
```

## 已验证结论

| 报告 | 核心结论 | 状态 |

| 评审意图 | 评审意图理解 15/15 稳定 | ✅ 已封装为 CLI |
| 母题提取 | 母题可被 LLM 提取（56-58% 覆盖率） | 🟡 验收合格 |
| 母题跨作品 | 母题跨作品可识别（F1=100% pairwise） | ✅ 验收优秀 |
| 母题生成 | 母题可作为生成约束（+20~45pp） | 🟡 验收合格 |
| 母题缝隙 | 母题缝隙分析与多向改进建议 | 🟡 验收合格 |
| 风格评审 | 复刻作者审美评审（内化 style.yaml 审美框架） | 🟡 验收合格 |
