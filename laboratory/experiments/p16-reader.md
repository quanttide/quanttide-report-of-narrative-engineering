# p16 模拟读者系统（E4）

验证 LLM 能否通过结构化 prompt 模拟特定读者视角，产生系统差异化且稳定的文本评价，实现"不需要真实读者即可做群体仿真"。

## 背景

实验室愿景的核心切换是从"规范审美"转向"描述审美"——系统不输出单一的好/坏判断，而是回答"什么样的读者在什么条件下会觉得好"。p16 是实现这一愿景的基础设施：建立一个可配置的"模拟读者"模型，给定文本 + 读者画像 → 输出该读者视角下的评价分布。

实验设计包含三层架构：层1（认知加工模拟层，客观认知负荷指标）、层2（读者画像层，参数→权重映射）、层3（群体仿真层，多画像批量评价聚合）。预期全链路为"层1 认知负荷 → 层2 权重映射 → 层3 分布输出"。

### 核心方法修正

实验过程中经历了三次关键修正：

| 修正 | 原因 | 影响 |
|------|------|------|
| **数值 prompt → 行为锚定** | 抽象人格参数（openness/empathy/NFC）无法驱动 LLM 稳定分化（sil=0.11），改用具名用户画像（"甜宠少女""职场丽人"等） | Phase I 核心假设成立的基础 |
| **硬性方向假设 → 无方向检验** | 所有心理学文献预期的方向假设全部错误（如 P2 高文学素养未必比 P1 更易识别"有意留白"） | 改用 η²（效应量）衡量"是否不同"而非"谁高谁低" |
| **规则公式 → LLM 标注** | 层1的句法规则（词频/标点/嵌套从句深度）与 LLM 语义理解完全不对齐（平均 ρ=0.041） | 层1降级为可选装饰层，核心能力直接通过 prompt 评价 |

## 结论

**LLM 能通过结构化 prompt 模拟分化读者，产生系统不同且稳定的文本评价。但全链路工程化路径（层1规则公式 → 层2权重回归）不可行——最终系统使用直接 prompt 评价模式，层1认知负荷保留为可选装饰层。**

### 画像评分模式

| 画像 | writing | emotional | character | cliche |
|:---|:---:|:---:|:---:|:---:|
| P1 甜宠少女 | 4.33 | 5.00 | 4.17 | 3.11 |
| P2 职场丽人 | 4.72 | 4.56 | 4.44 | 3.17 |
| P3 资深老书虫 | **5.11** | **5.39** | **5.94** | **1.72** |
| P4 消遣型 | 4.39 | 5.06 | 4.94 | 3.00 |
| P5 成熟婚恋 | 4.72 | 4.72 | 4.78 | 3.22 |

P3（资深老书虫）在所有质量维度上评分最高，在套路感上评分最低——是最"挑剔"的读者。P1（甜宠少女）情感冲击力评分最高——是最"感性"的读者。这两个模式在 Phase I 的 6 篇文本和 Phase II 的 4 篇新文本上均一致。

## 关键发现

1. **LLM 是"人情模型"而非"参数模型"**——具名用户画像（"甜宠少女""资深老书虫"）驱动 LLM 模拟的效果显著优于抽象人格参数（openness/empathy/NFC）。LLM 擅长角色扮演，不擅长从数字参数演绎行为。

2. **画像差异是真实且稳定的**——不同画像的评价模式不同（η²=0.219），且这种差异在 3 次独立调用间一致（ICC=0.914），在未见文本上可识别（分类准确率 41.1%）。但差异方向与心理学文献预期不一致——不能预测"谁高谁低"，只能测量"是否不同"。

3. **层1规则公式从根本上不可行**——句法层面的认知负荷特征（词频、标点密度、嵌套从句）与语义层面的理解（什么是"难读"的句子）是两个不同构念。ρ=0.041 说明两者几乎无重叠。

4. **回归权重映射路径因样本量不足不可行**——6 篇文本不足以支持 3 特征 × 4 因变量的回归。后验分析发现回归系数符号全同，不同画像的"权重差异"本质是各维度评分比例的差异。

5. **直接 prompt 模式可用且可靠**——最终系统去掉层1→层2 的回归路径，直接使用行为锚定 prompt 驱动 LLM 评价。4 篇新文本验证通过（ICC=0.62, 3/4 维度显著, η²=0.26, 模式一致）。

## 产品意义

1. **"模拟读者"核心能力可用**——系统能回答"不同类型的读者会怎么看这个文本"。这是"描述审美"愿景的基础设施。

2. **但不要过度工程化**——层1认知负荷和层2权重映射增加了复杂性但未提升预测能力。推荐方案：直接 prompt 评价 + 层1 LLM 标注作为可选的"为什么"解释层。

3. **产品中应使用具名用户画像**——与其让创作者配置数字参数（openness=0.8），不如直接选择"资深老书虫""职场丽人"等具名画像。LLM 对这种输入的理解更稳定。

4. **不能预测绝对评分方向**——系统能说"P3 和 P1 对这个场景的看法不同"，但不能说"P3 一定比 P1 更挑剔"。这是 LLM 模拟的内在限制，产品应在 UI 中避免呈现排名/方向性结论。

5. **模拟读者不等同于真实读者**——p16 只验证了 LLM 模拟的"分化性"和"稳定性"，未验证"生态效度"（与真实读者的对齐度）。所有模拟输出应标注为"模拟视角"，不参与最终评级。
