# p08 母题缝隙分析与多向改进实验

验证 LLM 能否检测初稿中的母题缝隙，并从 6 个方向（增强/引入/借用/转化/克制/反向）提出差异化改进建议。

## 背景

p05 证明母题可提取，p06 证明母题可跨作品识别，p07 证明母题可作为生成约束。p08 合三者为一：输入初稿 → 检测母题期望与实际的差距 → 输出多方向改进建议。这是三个前序实验的产品化整合。

## 实验设计

| 项 | 内容 |
|----|------|
| 测试文章 | 4 篇（D1 咖啡厅重逢、D2 酒吧表白、D3 第六章、D4 第十章 KTV） |
| 缝隙检测 | 对比 p05 提取结果 vs gallery motif.yaml，识别缺失/弱化母题 |
| 建议方向 | 增强 / 引入 / 借用 / 转化 / 克制 / 反向（每缝隙×6方向） |
| 评估维度 | 可行性、母题契合度、自然度、可操作性 |
| 模型 | DeepSeek Chat |

## 结论

**LLM 可检测初稿母题缝隙并生成 6 方向差异化改进建议。不同方向的质量有显著分化，"增强"和"转化"最可靠，"克制"是独特价值，"反向"有风险但偶有意外产出。**

## 关键数据

### 缝隙检测

| 文章 | 覆盖母题 | 缺失母题 | 弱母题 |
|------|---------|---------|--------|
| D1 咖啡厅重逢 | 雨 | 十年、手势、孤独、歌声 | 无 |
| D2 酒吧表白 | 十年 | 手势、雨、孤独、歌声 | 无 |
| D3 第六章 | 无 | 论坛、协作书写、旁观者、随身携带的温柔 | 无 |
| D4 第十章 KTV | 无 | 论坛、协作书写、旁观者、随身携带的温柔 | 无 |

缝隙识别准确率与 p05 覆盖率一致（D1 缺低 weight 母题，D2 缺高 weight 母题，D3/D4 大面积缺失）。

### 6 方向质量分化

| 方向 | 可行性 | 母题契合度 | 自然度 | 可操作性 | 评价 |
|------|--------|-----------|--------|---------|------|
| **增强** | 高 | 高 | 高 | 高 | 最安全——强化已有元素 |
| **转化** | 高 | 中高 | 中高 | 高 | 将场景元素改造为母题载体 |
| **引入** | 中 | 高 | 中 | 中 | 凭空加元素，可行性受限 |
| **借用** | 中 | 中高 | 中 | 中 | 跨作品变体有趣但需适配 |
| **克制** | 最高 | 最低 | 最高 | 高 | "不做修改"本身就是建议 |
| **反向** | 中高 | 中低 | 中低 | 中 | 最不可预测，偶有惊喜 |

### 关键发现

1. **"增强"和"转化"是安全建议**——改动小、不引入新元素、自然度高
2. **"克制"是独特的建议方向**——对 weight ≤ 5 的母题（如"歌声"），克制可能是最优解。D1 的"克制"建议被评估为"高于引入"
3. **"借用"的跨作品变体有效**——从校园"纸巾擦眼泪"借到都市"递毛巾"的递进逻辑，LLM 能识别结构一致性
4. **"反向"风险最高**——"有意违抗手势母题：他的手始终没有伸出"这种建议需要创作者判断是否值得尝试
5. **歌声母题最难处理**——所有方向的建议质量都偏低，因为它在当前场景中缺乏可操作的文本基础

## 产品意义

1. **母题系统可以成为编辑工具**——不只是事后分析，而是事前提供改进方向
2. **"克制"方向的确定是重要的产品设计决策**——"不做什么"和"做什么"同样有价值
3. **6 方向框架可以封装为 CLI 命令或 API 端点**
4. **不同缝隙类型需要不同的策略优先级**：
   - 缺高 weight 母题（如 D2 缺手势）→ 优先"增强"和"引入"
   - 缺低 weight 母题（如 D1 缺歌声）→ "克制"可能是最优解
   - 大面积缺失（如 D3/D4）→ 优先"转化"现有元素
