# 模拟读者：预览不同读者怎么看你的稿子

你写完一段酒吧表白，丢进系统，选"资深老书虫"。系统返回：文笔 5.11，套路感 1.72——她觉得不套路，但也没被打动。

切到"甜宠少女"：情感冲击 6.0——她心跳加速了。

两份评价的矛盾不是噪声，是数据。这就是**描述审美**：系统不输出单一的好坏判断，而是回答"什么类型的读者会怎么看"。

## 怎么用

| 你想做什么 | 现在能不能 |
|-----------|:--------:|
| 预览不同读者对一段文本的反应 | ✅ 可以 |
| 判断谁的评价更"正确" | ❌ 不能——这本来就不是它的设计目标 |
| 根据模拟反馈决定怎么修改 | ⚠️ 需要你自己判断，系统不替你做决定 |

### 你的读者是谁？

系统内置 5 个具名画像，覆盖都市言情主流读者：

| 画像 | 一句话 | 最看重 | 最不敏感 |
|------|--------|--------|---------|
| P1 甜宠少女 | 看小说就是为了开心 | 情感冲击 | 套路感 |
| P2 职场丽人 | 文笔和逻辑不能太差 | 整体质量 | — |
| P3 资深老书虫 | 套路一眼就能看出来 | 文本质量最高，套路要求最高 | — |
| P4 消遣型 | 就是打发时间 | 什么都行 | 所有维度 |
| P5 成熟婚恋 | 喜欢成年人之间的感情 | 情感真实性 | — |

选一个画像跑一次，得到它在四个维度的评分（1-7 分）：
- **writing_quality**：文笔
- **emotional_impact**：情感冲击力
- **character_realism**：角色真实感
- **cliche_level**：套路感（越低越好）

### 读结果的一个技巧

不需要理解这些维度，只需要比较差异。比如：

> P3 的套路感是 1.72，其他画像都在 3.0 以上——如果你的目标是打动老读者，套路感比文笔更重要。

## 它的能力边界

### 能做到的

- **分化**：不同画像对同一文本的评价确实不同，且差异不是随机噪声（η²=0.219。η² 是"效应量"，衡量画像不同这个因素解释了多少评分差异——0.219 意味着 22% 的评分差异来自"谁在读"，属于中等偏上效应）
- **稳定**：同一画像读同一段文本三次，评分高度一致（ICC=0.914。ICC 是组内相关系数，衡量多次测量的一致性——1.0 意味着每次完全一样，0.7 以上已算高度一致）
- **泛化**：在新文本上同样有效——模式在未见过的 4 篇文本上复现

### 做不到的

- **不能预测绝对方向**——系统能说"P3 和 P1 的感受不同"，但不能说"P3 一定比 P1 更挑剔"。工具应呈现差异，不呈现排名。

- **不能替你做决定**——模拟读者不等同于真实读者。系统只验证了"LLM 能模拟差异"，未验证"模拟差异与真实读者差异一致"。所有输出标注为"模拟视角"，不参与最终评级。

- **不能靠公式计算"难读程度"**——早期尝试用句法规则（词频、嵌套从句深度）测量认知负荷，发现这条路根本不通：公式与人的判断完全不相关（平均 ρ=0.041）。最终系统直接用 LLM 读文本做评价，效果足够。

## 一个完整案例

同一段文本（深夜失眠），两个画像的评分：

| 维度 | P1 甜宠少女 | P3 资深老书虫 |
|------|:--------:|:----------:|
| 文笔 | 4.33 | **5.11** |
| 情感冲击 | **5.00** | 5.39 |
| 角色真实感 | 4.17 | **5.94** |
| 套路感 | 3.11 | **1.72** |

P3 在所有质量维度上都比 P1 高，但套路感低了一半。这说明：这段文本不套路，但没有明显的情感爆发点——P1 没被击中，P3 认可质量但也没被打动。

如果你的目标是让两类读者都有反应，可能需要检查情感冲击力是否足够。

## 为什么叫"描述审美"

传统工具输出一个分（"这篇 8.6 分"），但 8.6 分对不同读者意味着完全不同的体验：

- 甜宠少女：情感冲击高 → "好看"
- 资深老书虫：套路感低 → "不套路，但也就那样"

这 22% 的评分差异（η²=0.219）不是噪声，是读者结构本身的差异。描述审美做的就是呈现这种结构——不是一个分数，而是一个分布。

## 怎么开始

```bash
cd apps/review
uv run python -m src e4-5    # 在 4 篇文本上跑全画像评价
```

输出是每个画像的评分矩阵。你不需要理解背后的 E4-0 到 E4-5 实验流程——它们只是验证过程，用一句话概括就够了：

> 系统验证了两件事：不同的读者画像确实会给出不同的评价（分化性），且同一张画像给同一段文本三次评分基本一致（稳定性）。这两个条件满足后，工具就可以用了。
