# 角色一致性检查器：你的角色会这样做吗？

写了一场戏，总觉得哪里不对——角色说了不符合性格的话，做了不符合设定的事。但你不确定：这是创作失误，还是有意挑战角色边界？

这个工具帮你回答这个问题。

## 开箱：一场戏能查出什么

你把《咖啡厅重逢》的稿子丢进去。它返回 6 个可能的 OOC 问题，其中这 4 个你可能真的需要看一眼：

| 角色 | 做了什么 | 问题 | 为什么 |
|------|---------|------|--------|
| 林远亭 | 掏毛巾擦她头发 | 社交越界 | 林远亭"谨慎""自我压抑"，主动做越界动作与性格不符 |
| 林远亭 | 直接点了焦糖玛奇朵 | 动机缺失 | 作为社交陌生人不应知道她的口味 |
| 陆知微 | 呆呆任由他擦 | 被动 OOC | 陆知微"勇敢主动"，完全被动不符合其性格 |
| 林远亭 | "知微女神！" | 对话 OOC | 回避型沟通风格不应使用昵称 |

注意：这些"问题"在原文中大部分是有意设计的张力——小说靠角色做不符合性格的事来制造冲突。工具的任务是标记出来，由你判断：这是失误，还是设计。

## 能帮你做什么

### 1. 知道角色什么时候容易跑偏

角色状态在两种时候预测力最强：**冲突高潮**和**第一次接触**。在这附近写的每一个动作、每一句对话，角色都高度受限——他只有 2-3 种合理的做法。

在关系稳定期，角色获得了更多行为自由，此时工具能提供的信息有限。

这不是工具的缺陷，是写作本身的规律：人物在冲突中比在平静中更"可预测"。

### 2. 发现你漏了一场戏

动机分数突然从 0.7 降到 0.3，同时替代路径分数飙升到 0.7——这就是一个自动标记：**这里可能缺了一个过渡**。

比如拥抱之后直接跳到表白：她说了"以后我陪你"，下一场就在酒吧说"我喜欢你"。缺的是那个"她决定今晚开口"的内在决策时刻。工具会标记这种跳跃。

### 3. 看见自己的决策偏好

每次做情节选择时，你都有一个"替代路径"——角色如果做了不同选择，故事会怎么走。工具会同时生成两个版本。

如果替代路径每次都比实际情节更合理，说明你在同一个模式上反复选择"克制/安全"的选项。这不是好坏问题，是你的**决策指纹**。

## 有多准

13 组成稿场景的逐对检验：

| 场景 | 动机一致性 | 场景一致性 |
|------|:--------:|:--------:|
| 咖啡厅→深夜失眠 | 0.7 | 0.7 |
| 便利店→夜市约会 | 0.7 | 0.7 |
| 海边→公园拥抱 | 0.7 | 0.7 |
| 公园→酒吧表白 | 0.3 | 0.3 |
| 酒吧→家里火锅 | 0.3 | 0.5 |
| 书房→客厅看剧 | 0.3 | 0.5 |

动机和场景分数在每对中都处于同一区间，差不超过 0.2。工具能判断**"会做什么类别的事"**（冲突/平静/日常），但不能判断**"具体怎么做"**（对话怎么写、细节怎么填）。

**一句话**：它告诉你这里可能有问题，但不告诉你该怎么改——那是你的工作。

## 怎么用

```
写完一个场景 → 跑检查器 → 看标记 → 判断是有意张力还是创作失误
                                   ↓
                              修改 / 保留并记录设计意图
```

## 原理（如果你好奇）

从全部场景文本中构建林远亭和陆知微的深度心理档案（人格特质、内心世界、行为模式、关系动态），然后逐句比对场景中的每个行为是否符合档案。

验证方法：用档案推理下一场情节，与实际的下一场对比——13 组相邻对，平均动机一致性 0.40，张力延续 0.46。（注：在中后期场景，角色行为自由度提高，预测力自然衰减，不是方法问题。）

## 当前限制

- 区分不了"有意 OOC"和"创作失误"——需要你来做判断
- 只在一部作品（职场言情）上验证过
- 场景一致性的天花板约 0.7——具体细节由你决定，不是工具的事
