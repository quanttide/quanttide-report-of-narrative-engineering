# 角色驱动的情节推理实验报告

> 状态：✅ 验收合格（已取代 p14、p15）
> 日期：2026-06-07
> 实验范围：职场言情系列（14 个成稿场景，1 位作者）
> 实验编号：p18（内部追溯用）

## 摘要

验证"角色状态是否编码了情节方向"——从文本中构建深度角色心理档案，然后用档案推理下一场情节，与 story.yaml 的实际情节对比。13 组相邻场景的实验表明：角色状态在大转折点附近有强预测力（动机准确率 0.7），但在关系稳定期预测力衰减（动机准确率 0.3）。（注：文件名中的"motif"属历史命名，实验实际操作对象为角色而非母题。）

## 实验设计

### 三阶段架构

```
Part A: 角色档案构建
  输入：当前场景及之前全部场景的文本
  输出：林远亭 + 陆知微的深度心理档案
        （人格特质、内心世界、行为模式、关系动态）
  方法：LLM 从文本中聚合提取

Part B: 情节推理
  输入：角色档案 + 当前场景全文
  输出：下一场核心事件 + 动机拆解 + 替代路径
  方法：LLM 基于角色约束推理

Part C: 评估
  输入：推理结果 + story.yaml 的实际下一场景
  输出：动机准确率、张力延续度、场景合理性、替代合理率
  方法：结构化评分 rubric（temperature=0.1，非自由评估）
```

### 关键方法论改进

| 改进 | 问题 | 方案 |
|------|------|------|
| 数据泄露 | 档案读到全部 14 个场景，包括要推理的下一场 | 隔离输入窗口——只用到当前场景为止的文本建档案 |
| 自评循环 | 同一个 LLM 推理+评估，倾向于说好 | 结构化评分 rubric，temperature=0.1，强制逐维打分解释 |
| 缺少基线 | 分数 0.6 是好是坏？ | 零假设——错位时间窗：用结尾档案推开头，开头档案推结尾 |
| 样本不足 | 4 组不够 | 全量 13 个相邻对 |

张力积累期（动机 ≥ 0.7）：
- 1_1→1_2（咖啡厅→失眠）：重逢冲击，心理状态密集
- 4_1→4_2（便利店→夜市）：试探期，方向清晰

- 2_1→2_3（展会→小龙虾）、2_3→4_1（小龙虾→便利店）

- `7_2 公园拥抱 → 8_2 酒吧表白`：动机下降 0.4，替代 0.7 → 可能缺失中间情节

## 核心结论

### 结论一：角色状态编码情节方向，但精确度因叙事节奏变化

角色状态在张力积累期（重逢、第一次接触、表白临界）有强预测力（动机 0.7），在张力释放后和关系稳定期预测力衰减（0.3）。这不是方法的缺陷，而是叙事本身的特征——角色在内心冲突强烈时行为被高度约束，在关系稳定后获得更多行为自由。

### 结论二：动机+张力分数的骤降可检测情节跳跃

7_2→8_2 的分数骤降（0.7→0.3）被自动标记为可能的跳跃点。实际文本中，从公园拥抱到酒吧表白之间确实缺少过渡——拥抱时她说"以后我陪你"，下一场就在酒吧表白。缺少一个"她决定今晚说出口"的内在决策时刻。

**这意味着动机+张力曲线可作为一种叙事结构分析工具**：自动标注出"这里可能缺了一场戏"。

### 结论三：替代路径分数揭示作者决策偏好

替代合理率在全书呈现出稳定的 0.7（除开头几组外），说明作者在多数情节节点上倾向于选择"克制"路径——不选择最戏剧化的发展，而是回归日常。这是作者的**决策指纹**。

### 结论四：角色状态是必要不充分条件

场景一致性的配对对比（动机 vs 场景）：

| 场景对 | 动机 | 场景 |
|--------|:---:|:---:|
| 1_1→1_2 | 0.7 | 0.7 |
| 4_1→4_2 | 0.7 | 0.7 |
| 6_2→7_2 | 0.7 | 0.7 |
| 7_2→8_2 | 0.3 | 0.3 |
| 8_2→9_1 | 0.3 | 0.5 |
| 10_1→10_2 | 0.3 | 0.5 |

动机和场景分数在每对中都处于同一区间（高/低同步），两者之差从未超过 0.2 分。这说明角色状态决定的"类别"（冲突 vs 日常）已经确定了情节的基调，具体的场景细节只是这个基调下的填充。角色状态约束的是"会做什么类别的事"，而不是"具体怎么做"。

## 产品定位：合理性检查器

实验结论直接指向一个工具定位：**角色一致性检查器**，不是情节生成器。

### 工具定义

```
输入：场景文本 + 角色档案
输出：[
  {"角色":"林远亭", "动作":"掏出毛巾擦头发", "一致分":0.3, "问题":"OOC_行为", "原因":"..."},
  {"角色":"陆知微", "动作":"呆呆地任由他擦",  "一致分":0.2, "问题":"OOC_行为", "原因":"..."}
]
```

### 创作者工作流

1. 写完一个场景
2. 运行检查器 → 标记出角色不一致的动作/对话
3. 创作者判断：这是一处失误，还是有意为之的张力？
4. 如果是失误 → 修改；如果是有意张力 → 保留，检查器分数成为"这里的设计意图是挑战角色性格"的记录

### Demo 结果

对 1_1（咖啡厅重逢）运行检查器，检出 6 个 OOC 问题：

| 角色 | 动作 | 严重 | 判断 |
|------|------|------|------|
| 林远亭 | 掏毛巾擦头发 | 严重=2 | 林远亭"谨慎""自我压抑"，主动做越界动作与性格不符 |
| 林远亭 | 直接点焦糖玛奇朵 | 严重=2 | 作为社交陌生人不应知道她的口味 |
| 陆知微 | 呆呆任由他擦 | 严重=2 | 陆知微"勇敢主动"，完全被动不符合其性格 |
| 林远亭 | "知微女神！" | 严重=2 | 回避型沟通风格不应使用昵称 |

这些"OOC"问题在文本中其实是有意设计的张力（"社交陌生人+心理熟人"的核心约束），但检查器当前无法区分"有意 OOC"和"创作失误"。这是下一个改进方向。

## 下一步

1. **区分"有意 OOC"与"创作失误"**——检查器当前把所有角色不一致都标记为问题，但小说中角色做出不符合性格的事往往正是张力的来源。需要引入"作者的意图标注"来校准。
2. **跨作品验证**——用校园言情的数据跑同样的实验，验证结论是否通用。
3. **作者决策指纹的聚类**——在更多作品上跑替代分数分布，建立跨作者的对比基准。
